# Token Weather 汉化增强版 (Claw'd Companion Edition)

一个常驻在输入提示符上方的 Claude Code 模组 (Mod)，实时播报上下文窗口占用状态，并提供全会话累计消耗与真实模型纯流式输出速率统计。  
采用极简克制的 **双行紧凑空间架构**：左侧为 2 行高的 Claude 官方陶土暖橙方块小蟹（Claw'd），顶部呈现即时台词言语，底部汇聚全维度监控与 Segments 彩色多阶暗轨进度条。

## 核心设计与特性

### 1. 纯净双行架构 (仅占 2 行高度)
- **零背景干扰**：彻底摒弃传统大画布和刺眼的全屏背景填充，不侵占宝贵的终端回滚视窗。
- **左侧 2 行高迷你方块小蟹**：
  - 采用 Anthropic 官方标志性 Terracotta 陶土暖橙色 (`#de7356`)；
  - 8 像素宽 × 4 像素高（通过半块字符 `▀`、`▄` 映射为仅 2 行高度）；
  - 零内存分配预渲染快照缓存，70ms 丝滑流畅帧率的原地踏步与随机眨眼动效；
  - 增量 IPC 优化：仅在小蟹步态或眼态变动时触发终端绘制，无多余终端重绘。

### 2. 第 1 行：认知动态、伴生言语与实时速率
- **当前占用百分比**：紧贴小蟹右侧，随天气健康度阶梯着色（如 `40%`）。
- **即时伴生台词与警报**：
  - 思考中、工具读取、代码编辑、外部命令等状态即时同步，告别打字机卡顿重绘；
  - 单轮任务结束后自动平稳回归守望天色状态；
  - **气象跨阶跃迁警报**：当上下文发生阶梯跳变（或 `/compact` 压缩释放）时，即时播报警报并提供中肯优化建议。
- **真实纯流式输出速率与首字延迟 (TTFT)**：
  - `⚡ 45/s`（亮黄）：基于 `performance.now()` 高精度单调时钟与 `turn.step` 纯流式 chunk 间隔精准测算，配合自适应 EWMA 指数移动平均平滑滤波，剔除网络延迟、前置思考耗时与工具耗时，真实还原物理吐字吞吐；
  - `(首字 0.3s)`（青色）：精准记录从发起请求到收到首个有效 token/chunk 的时间（Time To First Token），反映网络往返与 Prefill 调度响应效率。

### 3. 第 2 行：气象横幅、全维账本与历史走势
- **实时气象分级**：直观反映上下文窗口占用等级（☀ 晴朗 / ☁ 多云 / ☂ 阵雨 / ☇ 风暴 / ↯ 亟待压缩）。
- **Segments 多阶彩色进度条**：
  - 参考 claude-deck 风格的分段符（实心 `▰` 与空心 `▱`）；
  - 未占用槽位与两端括号采用深邃暗轨底色 (`#3a3936`)，完美融入深色终端；
  - 绿 -> 青 -> 黄 -> 洋红 -> 红 随占用阶梯点亮。
- **上下文精确读数**：如 `80k / 200k context`，并在 `/compact` 后即时自动刷新。
- **全会话累计消耗统计**：
  - `∑ 累计输入`（亮青）、`累计输出`（翠绿）；
  - `推理`（洋红，Thinking 思考消耗统计）；
  - `命中`（Prompt 缓存命中率百分比，内置防除零 NaN 容错保护）。
- **近几轮走势图**：真实保留跨轮次历史轨迹，直观呈现最近轮次上下文波动态势（如 `近几轮 ▂▅█ ▲ +52k/轮`）。

## 阶梯色彩与建议字典

| 占比区间 | 预报天气 | 阶梯色彩 | 变动建议说明 |
| :--- | :--- | :--- | :--- |
| **< 25%** | 晴朗 | ☀ 绿色 (`green`) | 空间极度充裕！尽情思考与编写，无需顾虑上下文负担~（放晴时：乌云散去，轻装上阵！） |
| **25% – 49%** | 多云 | ☁ 青色 (`cyan`) | 状态平稳健康，记忆脉络清晰，探索与多文件协作正常推进。 |
| **50% – 74%** | 阵雨 | ☂ 黄色 (`yellow`) | 降雨警觉！占用已过半。避免全量倾倒超大文件或冗余日志，多用精准定位与局部阅读。 |
| **75% – 89%** | 风暴 | ☇ 洋红色 (`magenta`) | 强风暴来袭！上下文较为紧张，建议尽快收尾交付当前子任务，防范信息过载。 |
| **≥ 90%** | 亟待压缩 | ↯ 红色 (`red`) | ⚠️ 紧急红警！临近上下文上限，强烈建议输入 `/compact` 进行记忆精简压缩，防止早期关键信息被截断！ |


```bash
claude plugin marketplace update token-weather-zh
claude plugin update token-weather@token-weather-zh
```

# Token Weather 汉化增强版 + 像素大剧场 (Crab Theater Mode)

一个运行在输入提示符上方的 Claude Code 模组 (Mod)，实时播报上下文窗口占用状态，并提供全会话累计消耗与真实模型纯流式输出速率统计。  
深度参考 [claude-deck](https://github.com/nvr0x5/claude-deck) 的 **Segments 分段多阶进度条 (`▰ ▱` 与深轨底色)**，并全面融合原版 [crab-theater](https://note.com/chankostin/n/nd31709bb3ed3) 的 **24-bit 9 行半块像素大舞台 (Raster Half-block Canvas)** 与 **Claude 官方吉祥物暖橙方块小蟹（Claw'd）**！

---

## 双版本分支架构

本项目提供两种满足不同偏好的分支版本：

| 分支 | 模式定位 | 特性与适用场景 |
| :--- | :--- | :--- |
| **`main` (默认)** | **像素大剧场模式**<br>*(Crab Theater Mode)* | • 包含顶部状态栏 + **9 行 24-bit 像素画布大舞台** (`Raster` 点阵引擎)<br>• Claude 官方陶土暖橙 (`#de7356`) 像素小方蟹，随轮次踏步迈步行走 + 随机眨眼<br>• 6 大动态场景随调用工具实时切换 (meadow, forge, rail, cave, space, sea)<br>• 动态滑入式任务标牌 + 伴生对话气泡 (`Speech Bubble`)，变色时大声播报警报与专业优化建议 |
| **`compact`** | **轻量极简字符版**<br>*(Compact 2-Line Bar)* | • 仅占用 2 行终端高度，纯字符渲染，0 光栅开销<br>• 包含完整天气气象、Segments 彩色多阶暗轨进度条、全会话统计与流式速率 |

## 核心功能与技术增强

### 1. 主气象与用量横幅（第 1 行）
- **实时气象分级**：直观反映上下文窗口占用等级（☀ 晴朗 / ☁ 多云 / ☂ 阵雨 / ☇ 风暴 / ↯ 亟待压缩）
- **claude-deck 同款 Segments 多阶彩色进度条**：
  - 采用实心分段符 `▰` 与空心分段符 `▱`；
  - **彻底告别刺眼灰色**：未占用槽位与两端括号全部采用深邃暗轨底色 (`#3a3936`)，融入暗色终端；
  - **分段阶梯着色**：根据槽位区间独立渲染（绿 -> 青 -> 黄 -> 洋红 -> 红 依次点亮）。
- **上下文百分比与精确实时数值**：如 `60% context  120k / 200k`
- **全会话累计输入与累计输出**：高亮色彩区分：累计输入（亮青 `cyan`）、累计输出（翠绿 `green`），**支持 turnId 严格去重防重**。
- **累计推理消耗（思考 token）**：高亮洋红（`magenta`，Thinking 专属色），统计思考生成的 token 消耗。
- **Prompt 缓存命中率**：高亮亮青色实时反映缓存读取占总输入比例（如 `命中 61%`）。
- **真实纯流式输出速率**：醒目亮黄（`yellow`，如 `⚡ 82.5/s`），**通过监听 `turn.step` 纯流式 chunk 间隔与 token 跨度耗时精确测算**，彻底剥离网络首包延迟（TTFT）、前置思考耗时与外部命令/工具执行时长，精准呈现大模型真实物理吐字吞吐！
- **历史走势柱状图**：最近 12 轮的块状字符走势（如 `近几轮 ▂▅█` 与增量趋势 `▲ +52k/轮`）。

### 2. 24-Bit 像素大剧场 (Crab Theater Mode)
- **Anthropic 官方标志性 Terracotta 陶土暖橙色 (`#de7356`)**：
  告别红色熟螃蟹 Emoji，换装纯正官方吉祥物方块小蟹造型。
- **原作者《crab-theater》同款 6 大动态场景**：
  - 📖 **草原采风 (Read)**：边框 `#9aa0a6`，高亮 `#e6c07b`
  - 🔨 **熔炉锻造 (Edit/Write/NotebookEdit)**：边框 `#ff6a2a`，高亮 `#ffb066`
  - 🚂 **铁道工坊 (Bash)**：边框 `#ff5577`，高亮 `#ff8fa8`
  - 🔍 **洞窟探宝 (Grep/Glob/ToolSearch)**：边框 `#b07a4a`，高亮 `#e0b33a`
  - 🌌 **星际穿梭 (WebSearch/WebFetch)**：边框 `#8d6be8`，高亮 `#b9a3ff`
  - ⛵ **远洋扬帆 (Agent/Skill)**：边框 `#4aa3d8`，高亮 `#9fd3f0`
- **变色气象警报与专业建议气泡**：
  在上下文发生跨阶梯变色或 `/compact` 压缩释放时，小方蟹在舞台气泡中大声播报，并给出优化提示。

## 阶梯色彩与建议字典

| 占比区间 | 预报天气 | 阶梯色彩 | 变动建议说明 |
| :--- | :--- | :--- | :--- |
| **< 25%** | 晴朗 | ☀ 绿色 (`green`) | 空间极度充裕！尽情思考与编写，无需顾虑上下文负担~（放晴时欢呼：乌云散去，轻装上阵！） |
| **25% – 49%** | 多云 | ☁ 青色 (`cyan`) | 状态平稳健康，记忆脉络清晰，探索与多文件协作正常推进。 |
| **50% – 74%** | 阵雨 | ☂ 黄色 (`yellow`) | 降雨警觉！占用已过半。避免全量倾倒超大文件或冗余日志，多用精准定位与局部阅读。 |
| **75% – 89%** | 风暴 | ☇ 洋红色 (`magenta`) | 强风暴来袭！上下文较为紧张，建议尽快收尾交付当前子任务，防范信息过载。 |
| **≥ 90%** | 亟待压缩 | ↯ 红色 (`red`) | ⚠️ 紧急红警！临近上下文上限，强烈建议输入 `/compact` 进行记忆精简压缩，防止早期关键信息被截断！ |

## 安装与更新方法

### 新安装
```bash
/plugin install token-weather --marketplace atri404/token-weather-zh
```

### 升级至最新版 (v1.0.0)
```bash
claude plugin marketplace update token-weather-zh
claude plugin update token-weather@token-weather-zh
```

### 切换至轻量字符分支 (compact)
```bash
git checkout compact
```

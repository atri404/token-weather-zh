# Token Weather (汉化增强版)

一个运行在输入提示符上方的 Claude Code 模组 (Mod)，实时播报上下文窗口占用状态，并提供会话累计花费与模型输出速率统计。

本项目基于 Anthropic 官方 [claude-code-playground](https://github.com/anthropics/claude-code-playground) 中的 `token-weather` 模组汉化与增强开发。

---

## 效果展示

```text
 ☂  阵雨  [█████░░░]  62% context  124k / 200k  ∑ 累计输入 221k 累计输出 18.8k 推理 6.5k 命中 61%  ⚡ 1.0k/s   近几轮 ▂▅█  ▲ +52k/轮
```

每轮主循环结束后，输入框上方的横幅会即时更新：

- **天气图标与等级**：直观反映当前上下文窗口的充裕程度（☀ 晴朗 / ☁ 多云 / ☂ 阵雨 / ☇ 风暴 / ↯ 亟待压缩）
- **高对比多阶彩色进度条**：如 `[█████░░░]`，随当前占用百分比及天气阶梯色彩动态变色（绿 -> 青 -> 黄 -> 洋红 -> 红）
- **上下文百分比与数值**：高亮色彩标识如 `62%`，附带 `context` 与 `124k / 200k`
- **全会话累计输入与累计输出**：高亮色彩区分：累计输入（亮青 `cyan`）、累计输出（翠绿 `green`）
- **累计推理消耗（思考 token）**：高亮洋红（`magenta`，Thinking 专属色），统计大模型思考生成的 token 消耗
- **Prompt 缓存命中率**：高亮亮青色实时反映缓存读取占总输入比例（如 `命中 61%`）
- **模型输出速率**：醒目亮黄（`yellow`，如 `⚡ 1.0k/s`），基于真实请求耗时与生成量精确计算
- **历史走势柱状图**：最近 12 轮的块状字符走势（如 `近几轮 ▂▅█`）
- **上一轮增量趋势**：如 `▲ +52k/轮`、`▼ -5k/轮` 或 `持平`

### 阶梯色彩与天气预报

| 占比区间 | 预报天气 | 标识、进度条及占比色彩 | 状态说明 |
| :--- | :--- | :--- | :--- |
| **< 25%** | 晴朗 | ☀ 绿色 (`green`) | 上下文极度充裕，状态极佳 |
| **25% – 49%** | 多云 | ☁ 青色 (`cyan`) | 正常交互，记忆完整健康 |
| **50% – 74%** | 阵雨 | ☂ 黄色 (`yellow`) | 占用过半，开始注意大文件读取 |
| **75% – 89%** | 风暴 | ☇ 洋红色 (`magenta`) | 占用偏高，风暴预警 |
| **≥ 90%** | 亟待压缩 | ↯ 红色 (`red`) | 临近上限，即将触发 Compact |

> **数据真实性说明**：所有数值均直接来自引擎底座 `$.session.usage()` 的真实统计，与状态栏完全同步，无多余网络请求。

## 安装方法

本模组自带 Marketplace 清单，可通过 Claude Code 插件系统一键安装：

```bash
/plugin install token-weather --marketplace atri404/token-weather-zh
```

或者本地开发临时载入：

```bash
claude --plugin-dir /path/to/token-weather-zh
```

## 兼容性与自适应

- **自适应宽度**：
  - `< 65 列`（窄屏）：精简显示天气、占用比例与 token 上限；
  - `65 ~ 84 列`（中屏）：加入会话累计消耗与输出速率；
  - `≥ 85 列`（宽屏）：完整呈现近 12 轮走势图与上一轮增量。
- **字体兼容**：采用单宽文本符号与标准数学符号，在任意等宽终端字体下均不错位。

# Token Weather (汉化增强版 + 桌面伴生宠物)

一个运行在输入提示符上方的 Claude Code 模组 (Mod)，实时播报上下文窗口占用状态，并提供全会话累计消耗与模型输出速率统计。  
同时融入灵感源自 [crab-theater](https://note.com/chankostin/n/nd31709bb3ed3) 的**终端桌面伴生宠物（Desk Pet）**，实现**完全 0 Token 额外开销**的常态动作守护，并在上下文天气颜色发生变动时即时弹出占用告警与专业建议。

本项目基于 Anthropic 官方 [claude-code-playground](https://github.com/anthropics/claude-code-playground) 中的 `token-weather` 模组汉化与深度增强开发。

## 效果展示

```text
 ☂  阵雨  [██████░░░░]  60% context  120k / 200k  ∑ 累计输入 221k 累计输出 18.8k 推理 6.5k 命中 61%  ⚡ 1.0k/s   近几轮 ▂▅█  ▲ +52k/轮
 🦀 (V・o・V) 小蟹播报 [气象变动]: 多云 ➔ 阵雨 (60% · 120k/200k) 💡 建议: 降雨警觉！占用已过半。避免全量倾倒超大文件或冗余日志，多用精准定位与局部阅读。
```

每轮主循环结束后，输入框上方的横幅会即时更新两行状态：

### 1. 主气象与用量横幅（第 1 行）
- **天气图标与等级**：直观反映当前上下文窗口的充裕程度（☀ 晴朗 / ☁ 多云 / ☂ 阵雨 / ☇ 风暴 / ↯ 亟待压缩）
- **分槽位多阶彩色进度条**：如 `[██████░░░░]`，不同占比区间采用独立对应色彩（绿 -> 青 -> 黄 -> 洋红 -> 红 依次点亮），清晰呈现各阶段容量分布
- **上下文百分比与数值**：高亮色彩标识如 `60%`，附带 `context` 与 `120k / 200k`
- **全会话累计输入与累计输出**：高亮色彩区分：累计输入（亮青 `cyan`）、累计输出（翠绿 `green`）
- **累计推理消耗（思考 token）**：高亮洋红（`magenta`，Thinking 专属色），统计大模型思考生成的 token 消耗
- **Prompt 缓存命中率**：高亮亮青色实时反映缓存读取占总输入比例（如 `命中 61%`）
- **模型输出速率**：醒目亮黄（`yellow`，如 `⚡ 1.0k/s`），基于真实请求耗时与生成量精确计算
- **历史走势柱状图**：最近 12 轮的块状字符走势（如 `近几轮 ▂▅█`）
- **上一轮增量趋势**：如 `▲ +52k/轮`、`▼ -5k/轮` 或 `持平`

### 2. 桌面伴生宠物（Desk Pet - 第 2 行）
- **零 Token 额外开销（0 额外成本）**：完全基于本地状态机与正则表达式实现，不发起任何模型 API 请求，零延迟、零费用。
- **颜色/天气改变即时提醒**：当上下文占用突破临界阶梯触发颜色变动（如 绿->青->黄->洋红->红，或 `/compact` 压缩后释放回暖）：
  - 宠物立即冒出专属表情与变色通报：`[气象变动]: 多云 ➔ 阵雨 (60% · 120k/200k)`
  - 智能给出针对性的优化建议（如：阵雨期避免全量读大文件、风暴期快速收拢交付任务、红区强烈建议输入 `/compact` 压缩、压缩后欢呼轻装上阵）。
- **常态动作与工具伴随**：颜色平稳时，小蟹安静伴随在侧，生动感知上一轮操作（阅览源码、编辑文件、执行命令、检索网络等）。

### 阶梯色彩与建议字典

| 占比区间 | 预报天气 | 阶梯色彩 | 宠物表情 | 变动建议说明 |
| :--- | :--- | :--- | :--- | :--- |
| **< 25%** | 晴朗 | ☀ 绿色 (`green`) | `(V ◕‿◕ V)` | 空间极度充裕！尽情思考与编写，无需顾虑上下文负担~ |
| **25% – 49%** | 多云 | ☁ 青色 (`cyan`) | `(V・ω・V)` | 状态平稳健康，记忆脉络清晰，探索与多文件协作正常推进。 |
| **50% – 74%** | 阵雨 | ☂ 黄色 (`yellow`) | `(V・o・V)` | 降雨警觉！占用已过半。避免全量倾倒超大文件或冗余日志，多用精准定位与局部阅读。 |
| **75% – 89%** | 风暴 | ☇ 洋红色 (`magenta`) | `(V°д°)V` | 强风暴来袭！上下文较为紧张，建议尽快收尾交付当前子任务，防范信息过载。 |
| **≥ 90%** | 亟待压缩 | ↯ 红色 (`red`) | `🚨 ₍ノ°Д°₎ノ` | ⚠️ 紧急红警！临近上下文上限，强烈建议输入 `/compact` 进行记忆精简压缩，防止早期关键信息被截断！ |

## 安装与更新方法

本模组自带 Marketplace 清单，可通过 Claude Code 插件系统一键安装或更新：

### 新安装
```bash
/plugin install token-weather --marketplace atri404/token-weather-zh
```

### 已安装升级至最新版 (v0.6.0)
```bash
claude plugin marketplace update token-weather-zh
claude plugin update token-weather@token-weather-zh
```

## 兼容性与自适应

- **自适应宽度**：
  - `< 60 列`（极窄屏）：精简为单行显示天气、占用比例与 token 上限；
  - `60 ~ 89 列`（中屏）：完整展示两行（主状态栏 + 桌面伴生宠物行）；
  - `≥ 90 列`（宽屏）：额外激活近 12 轮走势图与上一轮增量。
- **字体兼容**：采用单宽文本符号与标准 Unicode 块状符号，在任意等宽终端字体下均不错位。

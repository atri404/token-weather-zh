# Token Weather (汉化增强版 + 桌面伴生宠物)

一个运行在输入提示符上方的 Claude Code 模组 (Mod)，实时播报上下文窗口占用状态，并提供全会话累计消耗与真实模型输出速率统计。  
同时深度参考 [claude-deck](https://github.com/nvr0x5/claude-deck) 的高级 **Segments 分段多阶进度条 (`▰ ▱` 与深轨底色)**，并融入源自 [crab-theater](https://note.com/chankostin/n/nd31709bb3ed3) 的**终端桌面伴生宠物（Desk Pet - 6 大场景道具与零 Token 开销）**：在上下文天气颜色变动时即时弹出醒目的气象警报/喜讯看板与专业优化建议！

本项目基于 Anthropic 官方 [claude-code-playground](https://github.com/anthropics/claude-code-playground) 中的 `token-weather` 模组汉化与深度增强开发。

## 效果展示

```text
 ☂  阵雨  [▰▰▰▰▰▰▱▱▱▱]  60% context  120k / 200k  ∑ 累计输入 221k 累计输出 18.8k 推理 6.5k 命中 61%  ⚡ 68.5/s   近几轮 ▂▅█  ▲ +52k/轮
 🦀 (V・o・V) [气象变动警报]: 多云 ➔ 阵雨 (60% · 120k/200k) 💡 建议: 降雨警觉！占用已过半。避免全量倾倒超大文件或冗余日志，多用精准定位与局部阅读。
```
*(常态平稳时，小蟹切换为场景守护看板，例如：`🦀 (V ◕‿◕ V)ミ 草原采风: 翻阅草丛卷轴 [auth.ts] · 气象阵雨`)*

每轮主循环结束后，输入框上方的横幅会即时呈现两行交互状态：

### 1. 主气象与用量横幅（第 1 行）
- **天气图标与等级**：直观反映当前上下文窗口的充裕程度（☀ 晴朗 / ☁ 多云 / ☂ 阵雨 / ☇ 风暴 / ↯ 亟待压缩）
- **claude-deck 同款 Segments 高级分段彩色进度条**：
  - 采用实心扁平分段符 `▰` 与低调空心分段符 `▱`；
  - **彻底告别刺眼灰色**：未占用槽位与两端括号全部采用深邃暗轨底色 (`#3a3936`)，在黑底终端下形成高雅的硬件刻度感；
  - **分段阶梯着色**：已占用部分根据槽位区间独立渲染（绿 -> 青 -> 黄 -> 洋红 -> 红 依次点亮），容量结构一目了然。
- **上下文百分比与数值**：高亮色彩标识如 `60%`，附带 `context` 与 `120k / 200k`
- **全会话累计输入与累计输出**：高亮色彩区分：累计输入（亮青 `cyan`）、累计输出（翠绿 `green`）
- **累计推理消耗（思考 token）**：高亮洋红（`magenta`，Thinking 专属色），统计大模型思考生成的 token 消耗
- **Prompt 缓存命中率**：高亮亮青色实时反映缓存读取占总输入比例（如 `命中 61%`）
- **模型真实输出速率**：醒目亮黄（`yellow`，如 `⚡ 68.5/s`），**通过监听 `turn.step` 纯流式耗时计算**，彻底排除前置思考等待、网络首包握手（TTFT）与外部工具执行时长，精准还原模型真实吐字吞吐！
- **历史走势柱状图**：最近 12 轮的块状字符走势（如 `近几轮 ▂▅█`）
- **上一轮增量趋势**：如 `▲ +52k/轮`、`▼ -5k/轮` 或 `持平`

### 2. 桌面伴生宠物（Desk Pet - 第 2 行）
- **零 Token 额外开销（0 额外成本）**：完全基于本地状态机与正则表达式实现，不发起任何模型 API 请求，零延迟、零费用。
- **颜色/天气改变即时提醒（气象变动警报 / 放晴喜讯）**：
  当上下文占用突破临界阶梯触发颜色变动（如 绿->青->黄->洋红->红，或 `/compact` 压缩后释放回暖）：
  - 宠物立即切换至警报看板：`🦀 (V・o・V) [气象变动警报]: 多云 ➔ 阵雨 (60% · 120k/200k)`
  - 智能给出针对性的优化建议（如：阵雨期避免全量读大文件、风暴期快速收拢交付任务、红区强烈建议输入 `/compact` 压缩、压缩后欢呼轻装上阵）。
- **6 大场景道具伴随与步态微动作**：
  常态平稳时，小蟹自动根据最近调用的工具切换场景、步态与道具看板：
  - 📖 **草原采风 (Read)**：`🦀 (V ◕‿◕ V) 草原采风: 翻阅草丛卷轴 [auth.ts]`
  - 🔨 **熔炉锻造 (Edit/Write/NotebookEdit)**：`🦀 (V・ω・V) 熔炉锻造: 淬火锻打源码 [main.rs]`
  - ⚡ **城塞工坊 (Bash)**：`🦀 (V・o・V) 城塞工坊: 操纵工坊矿车 [git status]`
  - 🔍 **洞窟探宝 (Grep/Glob/ToolSearch)**：`🦀 (V・ω・V) 洞窟探宝: 提灯探测矿脉 ["token"]`
  - 🌌 **星际穿梭 (WebSearch/WebFetch)**：`🦀 (V ◕‿◕ V) 星际穿梭: 跃入星轨检索 [note.com]`
  - ⛵ **远洋扬帆 (Agent/Skill)**：`🦀 ٩(◕‿◕)۶ 远洋扬帆: 乘风调度智能体`
  - ☕ **营地小憩 (待命闲置)**：`🦀 (V・-・V)旦 营地小憩: 守望天色 · 待命中`

| 占比区间 | 预报天气 | 阶梯色彩 | 宠物表情 | 变动建议说明 |

## 安装与更新方法

本模组自带 Marketplace 清单，可通过 Claude Code 插件系统一键安装或更新：

### 新安装
```bash
/plugin install token-weather --marketplace atri404/token-weather-zh
```

### 已安装升级至最新版 (v0.7.0)
```bash
claude plugin marketplace update token-weather-zh
claude plugin update token-weather@token-weather-zh
```

## 兼容性与自适应

- **自适应宽度**：
  - `< 60 列`（极窄屏）：精简为单行显示天气、占用比例与 token 上限；
  - `60 ~ 89 列`（中屏）：完整展示两行（主状态栏 + 桌面伴生宠物场景行）；
  - `≥ 90 列`（宽屏）：额外激活近 12 轮走势图与上一轮增量。
- **字体兼容**：采用单宽文本符号与标准 Unicode 几何字符，在任意等宽终端字体下均不错位。
